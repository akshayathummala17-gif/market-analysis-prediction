## 🌟 Project Overview

The **Smart Temperature Analyzer & Converter with Intelligent Alerts** is an engineering micro project that bridges core procedural C programming with a modern interactive monitoring dashboard. 

The system validates physical thermodynamic boundaries (rejecting impossible values below Absolute Zero), performs exact mathematical conversion between **Celsius (°C)**, **Fahrenheit (°F)**, and **Kelvin (K)**, classifies environmental conditions into five distinct categories, and triggers automated intelligent alerts.

### 🎨 Special Dynamic Ambient Theme (Requirement 16)
- **High Temperature (> 25°C & > 35°C):** The entire display morphs into glowing **Crimson Red**.
- **Medium Temperature (15°C to 25°C):** The entire display stays in a soothing **Mild Emerald / Balanced Teal**.
- **Low Temperature (<= 15°C, Freezing & Cold):** The entire display morphs into frosty **Ice Blue / Royal Blue**.

## 🚀 Key Modules & Features

1. **Temperature Conversion Module:**
   - Multi-scale conversion between Celsius, Fahrenheit, and Kelvin.
   - Conversion formulas:
     - $F = (C \times 9/5) + 32$
     - $K = C + 273.15$
     - $C = (F - 32) \times 5/9$
     - $K = (F - 32) \times 5/9 + 273.15$
     - $C = K - 273.15$
     - $F = (K - 273.15) \times 9/5 + 32$

2. **Smart Input Validation:**
   - Checks against physical absolute zero limits:
     - Celsius: $\ge -273.15^\circ\text{C}$
     - Fahrenheit: $\ge -459.67^\circ\text{F}$
     - Kelvin: $\ge 0\text{ K}$
   - Rejects non-numeric, empty, or impossible inputs with descriptive error warnings and input shake animations.

3. **Condition Classification & Automated Alerts:**
   - **Freezing ($\le 0^\circ\text{C}$):** "Very cold temperature detected." (Frost hazard alert)
   - **Cold ($> 0^\circ\text{C}$ to $15^\circ\text{C}$):** "Low temperature detected." (Chilly alert)
   - **Normal ($> 15^\circ\text{C}$ to $25^\circ\text{C}$):** "Temperature is in the normal project-defined range." (Optimal equilibrium)
   - **Warm ($> 25^\circ\text{C}$ to $35^\circ\text{C}$):** "Warm temperature detected." (Hydration advisory)
   - **Hot ($> 35^\circ\text{C}$):** "High temperature detected." (Heatwave advisory)

4. **Persistent Audit History & Statistics:**
   - Stores logs using browser `localStorage`.
   - Displays latest 5 readings with expandable view.
   - Computes Total Valid Readings, Highest, Lowest, and Arithmetic Average temperature.
   - Dynamic interactive charts powered by **Chart.js**:
     - Category Distribution (Doughnut Chart)
     - Chronological Trendline (Line Chart)

5. **Download Report Suite:**
   - **Printable Lab Report Modal:** Official formatted technical sheet with student credentials, summary statistics, complete audit logs, and signature fields for faculty evaluation.
   - **CSV Export:** `temperature_audit_report.csv` for spreadsheet analysis.
   - **C-Compatible TXT Export:** `temperature_report.txt` matching the file format generated by the C program.

## 🛠️ C Programming Concepts Demonstrated

## 💻 How to Run the Project

### 1. Web Dashboard
Simply open `index.html` in any modern web browser (Google Chrome, Microsoft Edge, Mozilla Firefox, Safari).
```bash
# In PowerShell:
Start-Process index.html
```

### 2. C Program Execution
Compile and execute the C source code with GCC:
```bash
# Compilation (C99 standard)
gcc -Wall -Wextra -std=c99 temperature_analyzer.c -o temp_analyzer.exe

# Run the executable
.\temp_analyzer.exe
```
